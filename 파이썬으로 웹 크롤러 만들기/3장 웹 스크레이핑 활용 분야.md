## 3.1 프로젝트 분류하기

웹 스크레이핑 프로젝트는 먼저 **타깃형인지 광범위형인지** 구분할 수 있다.

타깃형 스크레이핑은 특정 사이트나 특정 페이지에서 정해진 데이터를 가져오는 방식이다. 대상 구조를 미리 알고 있으므로 사이트에 맞는 코드를 작성할 수 있다.

반면 광범위한 스크레이핑은 여러 사이트를 탐색하거나 새로운 대상을 동적으로 발견해야 한다. 사이트마다 구조가 다르므로 훨씬 일반적인 크롤러 구조가 필요하고 개발 난도가 높다.

또 하나 중요한 기준은 **일회성 프로젝트인지 지속적으로 실행되는 프로젝트인지**이다. 한 번 데이터를 가져오고 끝난다면 코드의 유지보수성보다 빠른 데이터 확보가 중요할 수 있다. 반대로 모니터링이나 데이터 갱신처럼 반복 실행한다면 사이트 구조 변경, 장애, 데이터 누락 등에 대응할 수 있도록 유지보수 가능한 코드와 모니터링 환경이 필요하다.

마지막으로 **수집한 데이터 자체가 결과물인지, 추가 분석의 입력값인지**도 구분해야 한다. 단순 데이터 수집이라면 DB·CSV 등에 저장하면 되지만, 분석이나 머신러닝 등에 사용할 경우 데이터 품질과 전처리까지 고려해야 한다.

즉,

**문제 정의 → 필요한 데이터 결정 → 대상 사이트 결정 → 수집 방법 결정 → 저장/분석 방법 결정**

순서로 프로젝트를 설계하는 것이 핵심이다.

### 3.2 이커머스

웹 스크레이핑이 가장 많이 활용되는 분야 중 하나다. 경쟁 쇼핑몰의 **상품 정보, 가격, 옵션, 재고, 할인, 리뷰** 등을 수집할 수 있다.

상품을 추적할 때 중요한 개념이 **SKU(Stock Keeping Unit)**다. 같은 제품이라도 크기·색상·스타일 등 옵션에 따라 서로 다른 SKU를 가질 수 있다. 따라서 단순히 상품 이름만 저장하는 것이 아니라 각 옵션을 구분하여 추적해야 한다.

특히 중요한 데이터는 다음과 같다.

- 상품 가격 및 가격 변동
- 옵션별 SKU
- 재고 수량
- 정상 가격과 할인 가격
- 리뷰와 평점

재고 수량은 화면에 직접 표시되지 않더라도 HTML이나 API 등에 포함되어 있을 수 있다. 이를 시간에 따라 기록하면 상품 판매량이나 재고 변화도 추정할 수 있다.

가격 역시 현재 가격만 보는 것보다 **시간에 따른 가격 변화**를 저장하는 것이 중요하다. 이를 통해 경쟁사의 할인 정책이나 프로모션 전략을 분석할 수 있다.

리뷰 데이터는 제품의 인기나 소비자 반응, 트렌드를 분석하는 데 활용할 수 있다.

#### 3.2.1 마케팅

마케팅에서는 대량의 온라인 데이터를 사람이 직접 조사하는 작업을 자동화할 수 있다.

대표적으로 **브랜드 모니터링**이 있다. 웹에서 자사 브랜드명, 제품명, 리뷰 등을 수집하여 브랜드가 어떻게 언급되고 있는지 파악한다. 상표권 침해나 이미지 무단 사용 등을 탐지하는 데도 활용할 수 있다.

다만 브랜드 관련 게시물이 모두 침해 행위인 것은 아니므로 단순히 브랜드명이 등장했다는 이유만으로 판단해서는 안 된다.

자사 브랜드뿐 아니라 **경쟁사의 제품, 리뷰, 언급량** 등을 함께 모니터링하면 시장 반응과 경쟁 상황을 분석할 수도 있다.

소셜 미디어 역시 중요한 데이터 원천이다. 게시물의 좋아요, 공유, 댓글 등의 반응을 수집하면 어떤 콘텐츠가 관심을 받는지 분석할 수 있다. 텍스트 길이, 이미지 포함 여부, 언어 등 여러 속성을 비교하여 목표 고객에게 효과적인 콘텐츠의 특성을 파악할 수도 있다.

또한 특정 분야에서 영향력이 큰 사용자를 찾고, 해당 사용자가 자주 다루는 주제를 분석하여 **인플루언서 마케팅 대상**을 탐색하는 데도 활용할 수 있다.

단, 소셜 미디어는 API 제한이나 기술적·법적 데이터 접근 제한이 존재하므로 사이트의 정책과 이용 조건을 고려해야 한다.

### 3.3 학술 연구

웹 스크레이핑은 상업적 목적뿐 아니라 **의학, 사회학, 심리학, 컴퓨터과학 등의 연구**에서도 활용된다.

예를 들어 온라인 게시물이나 댓글을 수집하여 사회적 현상을 분석하거나, 여러 기관이 공개한 자료를 한꺼번에 수집하여 연구 데이터셋을 구축할 수 있다.

책에서는 사례로 HIV 관련 온라인 데이터를 분석한 연구, 신문의 비만 관련 기사 댓글 분석, 대학의 마케팅 자료 분석 등을 소개한다.

또한 **대안적 데이터(alternative data)** 수집에도 활용된다. 일반적인 GDP 통계나 기업 재무제표가 아닌 웹상의 다양한 데이터를 수집하여 기존 통계를 보완하거나 새로운 지표를 만드는 방식이다.

다만 연구에서는 특히 **윤리 문제**를 고려해야 한다. 기술적으로 수집할 수 있는 데이터라고 해서 연구 목적으로 자유롭게 사용할 수 있는 것은 아니며 개인정보, 연구윤리 등을 사전에 검토해야 한다.

### 3.4 제품 개발

웹 스크레이핑은 새로운 서비스를 만들거나 **MVP(Minimum Viable Product)**를 빠르게 검증할 때 유용하다.

초기 서비스는 자체적으로 충분한 데이터를 보유하지 않은 경우가 많다. 이때 공개된 웹 데이터를 수집하면 적은 비용으로 서비스 아이디어를 시험할 수 있다.

예를 들어 여행 서비스를 만든다면 여러 사이트에서 **인기 관광지와 액티비티 목록**을 수집하여 초기 콘텐츠를 구축할 수 있다.

제품 리뷰 서비스라면 온라인 쇼핑몰에서 제품명, 키워드, 설명 등을 수집하고 생성형 AI 등을 활용해 초기 리뷰 콘텐츠나 분석 기능을 만들 수도 있다.

머신러닝 서비스에서도 웹 스크레이핑은 **학습 데이터셋 구축**에 활용된다. 모델 개발에는 많은 데이터가 필요하므로 인터넷의 공개 데이터를 체계적으로 수집하는 것이 중요한 데이터 확보 방법이 될 수 있다.

기업의 B2B 서비스에서도 산업 공급업체, 전문가 연락처, 채용 정보 등 여러 사이트에 흩어진 정보를 수집하여 하나의 데이터 서비스로 만들 수 있다.

### 3.5 여행

여행 산업에서는 호텔, 항공사, 렌터카처럼 **가격과 상품 정보가 지속적으로 변하는 데이터**가 많기 때문에 웹 스크레이핑의 활용도가 높다.

가격 데이터를 주기적으로 수집하면 경쟁사의 가격 변화를 파악하거나 시장의 가격 추세를 분석할 수 있다.

또한 여러 여행 사이트에서 데이터를 수집하여 **여행 정보 집계 서비스(aggregator)**를 만들 수도 있다.

여행 사이트들은 검색엔진에는 정보가 노출되기를 원하지만 경쟁사가 대량으로 데이터를 가져가는 것은 막고 싶어 한다. 그래서 웹 크롤러를 완전히 차단하기보다는 특정 크롤러나 행동 패턴을 선택적으로 제한하기도 한다.

한 사이트에서 데이터 수집이 어려워지더라도 동일하거나 비슷한 정보를 제공하는 다른 사이트를 데이터 소스로 활용할 수도 있다.

### 3.6 영업

웹 스크레이핑은 **잠재 고객(lead) 발굴**에도 활용된다.

기업 사이트, 디렉터리, 채용 사이트 등에서 회사명, 담당자, 연락처, 업종 등의 정보를 수집하여 영업 대상 목록을 구축할 수 있다.

채용 분야에서도 비슷하게 사용된다. 채용 담당자는 구직자 프로필이나 공개된 이력 정보를 수집하여 특정 직무에 적합한 후보자를 탐색할 수 있다.

또한 Yelp와 같은 비즈니스 디렉터리에서 지역, 업종, 서비스 유형 등의 조건으로 업체 정보를 수집하면 영업 대상을 세분화할 수 있다.

단순 연락처뿐 아니라 웹사이트의 기술적 정보도 활용 가능하다. 예를 들어 사이트의 HTML이나 코드를 분석하면 **사용 중인 CMS, 서버 기술, 분석 도구, 광고 기술** 등을 파악할 수 있다. 이를 통해 특정 기술을 사용하는 기업만 선별하여 관련 제품을 판매하는 식의 영업 전략을 세울 수 있다.

즉 영업 분야에서는

**웹 데이터 → 잠재 고객 식별 → 고객 특성 분석 → 영업 대상 세분화**

과정으로 활용된다.

### 3.7 SERP 스크레이핑

- **SERP(Search Engine Results Page)**는 검색 엔진 결과 페이지를 의미한다.

웹사이트를 하나씩 직접 방문해서 데이터를 가져오는 대신, 검색엔진이 이미 수집·정리해 놓은 결과를 활용하는 방식이다.

검색 결과 페이지는 여러 웹사이트의 정보를 어느 정도 **일관된 형식으로 정리해 준다는 장점**이 있다. 원본 사이트들은 HTML 구조가 모두 다르지만 검색엔진 결과는 상대적으로 일정한 형태를 갖기 때문에 데이터 수집이 쉬워질 수 있다.

예를 들어 과거 스포츠 리그 순위를 조사한다고 하자. NHL, NFL 등 각 리그 공식 사이트는 서로 다른 형식으로 정보를 제공한다. 각각에 맞는 스크레이퍼를 만드는 대신 검색엔진에서 특정 연도와 리그의 순위를 검색하고 결과를 수집하면 보다 일관된 방식으로 데이터를 확보할 수 있다.

SERP 스크레이핑은 특히 **검색 결과의 순위 자체**를 분석하는 데도 활용된다. 특정 검색어에서 어떤 사이트가 몇 번째에 등장하는지 기록하면 검색 노출 순위의 변화를 추적할 수 있다.

검색 광고 분석에도 활용할 수 있다. 특정 키워드를 검색했을 때 어떤 광고가 노출되는지, 광고의 순서는 어떤지, 시간에 따라 어떻게 변하는지 모니터링할 수 있다.

구글 지도, 구글 이미지, 구글 쇼핑 등 일반 웹 검색 이외의 검색 서비스도 데이터 소스로 사용할 수 있다.

또한 검색엔진은 웹페이지의 정보를 이해하기 위해 **구조화된 데이터(Structured Data)**를 사용한다. 웹사이트가 검색엔진에게 콘텐츠의 의미를 전달하기 위해 일정한 형식으로 데이터를 제공하므로, 이를 활용하면 웹페이지의 복잡한 HTML 구조를 직접 분석하는 것보다 쉽게 정보를 추출할 수 있는 경우가 있다.
