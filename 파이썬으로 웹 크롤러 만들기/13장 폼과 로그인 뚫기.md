## 13.1 requests 라이브러리

- urllib(urllib2)은 단순한 작업에도 손이 많이 가서, 복잡한 HTTP 요청, 쿠키, 헤더를 잘 다루는 서드파티 라이브러리 requests를 사용합니다.
- 설치는 `pip install requests`로 합니다.

## 13.2 기본적인 폼 전송

웹 폼은 입력 필드, 전송 버튼, 실제 처리를 맡는 액션 페이지로 구성됩니다. 폼을 흉내 낼 때 기억할 것은 두 가지입니다.

- **필드의 name 속성**: POST로 서버에 전달될 변수 이름이므로 정확히 맞춰야 합니다.
- **폼의 action 속성**: 요청은 폼이 있는 페이지가 아니라 action이 가리키는 처리 페이지(예: processing.php)로 보내야 합니다.

```python
import requests
params = {'firstname': 'Ryan', 'lastname': 'Mitchell'}
r = requests.post('https://pythonscraping.com/pages/files/processing.php', data=params)
print(r.text)
```

action이 명시되지 않고 자바스크립트가 전송을 처리하는 폼도 있습니다. 이때는 브라우저 개발자 도구의 네트워크 탭에서 실제 요청을 확인하면 됩니다. 책의 소식지 구독 폼은 admin-ajax.php로 전송되고 있었고, Payload 탭에서 화면에 보이지 않는 네 번째 값 `action: eclg_add_newsletter`까지 함께 보내야 한다는 사실을 찾아냅니다. 성공하면 JSON 응답이 돌아옵니다.

## 13.3 라디오 버튼, 체크박스, 기타 필드

- 필드 종류가 아무리 다양해도 결국 신경 쓸 것은 **필드 이름과 값**뿐입니다.
- 이름은 소스의 name 속성에서 쉽게 확인되지만, 값은 전송 직전에 자바스크립트가 만들어낼 수도 있어 까다롭습니다.
- GET 폼이라면 URL의 쿼리 스트링(`?thing1=foo&thing2=bar`)이 곧 매개변수이므로 그대로 딕셔너리로 옮기면 됩니다.
- POST 폼이 복잡하다면 F12로 크롬 개발자 도구를 열어 네트워크 탭의 Form Data를 보는 것이 가장 쉽습니다.

## 13.4 파일과 이미지 전송

업로드 폼은 `enctype="multipart/form-data"`이고 input의 type이 file이라는 점만 다릅니다. requests에서는 data 대신 files 매개변수에 문자열이 아닌 파일 객체를 넘깁니다.

```python
files = {'uploadFile': open('files/python.png', 'rb')}
r = requests.post('http://pythonscraping.com/pages/files/processing2.php', files=files)
```

참고로 본문 설명에는 경로가 files/Python-logo.png로 되어 있어 코드와 일치하지 않는데, 실습할 때는 실제 가지고 있는 파일 경로를 쓰면 됩니다.

## 13.5 로그인과 쿠키 처리

- 대부분의 사이트는 로그인 성공 시 브라우저에 쿠키(토큰, 만료일, 추적 정보 등)를 저장하고, 이후 페이지마다 이를 인증 증거로 사용합니다.
- 스크레이퍼가 로그인 자체는 할 수 있어도, 받은 쿠키를 다음 요청에 실어 보내지 않으면 로그인하지 않은 사용자로 취급됩니다.

**방법 1. 쿠키를 직접 전달**: 로그인 응답의 `r.cookies`를 프로필 페이지 요청에 `cookies=r.cookies`로 넘깁니다. 단순한 경우엔 되지만, 사이트가 쿠키를 수시로 바꾸면 깨지기 쉽습니다.

**방법 2. Session 사용 (권장)**: `requests.Session()` 객체가 쿠키, 헤더, HTTPAdapter 같은 연결 정보까지 알아서 유지합니다.

```python
session = requests.Session()
session.post('https://pythonscraping.com/pages/cookies/welcome.php', data=params)
r = session.get('https://pythonscraping.com/pages/cookies/profile.php')
```

저자는 라이브러리에 맡기더라도 쿠키가 어떻게 생겼고 무슨 일을 하는지 파악해 두면 디버깅 시간이 크게 줄어든다고 강조합니다.

### 13.5.1 HTTP 기본 접근 인증

쿠키 이전에 쓰이던 방식으로, 브라우저 팝업으로 아이디와 비밀번호를 받습니다. 지금도 보안이 중요한 사이트나 API에서 가끔 쓰입니다. requests의 auth 모듈로 처리합니다.

```python
from requests.auth import HTTPBasicAuth
auth = HTTPBasicAuth('ryan', 'password')
r = requests.post(url='http://pythonscraping.com/pages/auth/login.php', auth=auth)
```

실패하면 접근 거부 페이지가 반환됩니다.

## 13.6 기타 폼 문제

- 웹 폼은 악성 봇의 주요 공격 대상이라, 최신 사이트의 폼에는 눈에 보이지 않는 보안 장치가 숨어 있는 경우가 많습니다.
- CAPTCHA는 16장(이미지 처리와 텍스트 인식), 허니팟과 숨김 필드 같은 폼 보호 수단은 17장에서 다룹니다.
