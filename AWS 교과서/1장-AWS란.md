## 1.1 클라우드 컴퓨팅

### 1.1.1 클라우드 컴퓨팅이란

- **온프레미스(on-premises)**: 사용자가 직접 공간과 자원을 구축·운영하는 전통적인 IT 자원 구축 방식. 부담과 비용이 큼
- **클라우드(cloud)**: 인터넷 구간 어딘가에 눈에 보이지 않는 형태로 구성된 IT 자원 집합
- **클라우드 컴퓨팅(cloud computing)**: 인터넷을 통해 요구가 있을 때 즉시(온디맨드) IT 자원을 제공하고, 사용한 만큼 비용을 지불하는 서비스

### 1.1.2 클라우드 컴퓨팅 이점

- **민첩성**: 컴퓨팅·스토리지·DB 등 인프라부터 IoT, 머신러닝, 빅데이터까지 필요한 자원을 빠르게 구동
- **탄력성**: 비즈니스 요구에 맞춰 자원을 손쉽게 확장·축소하여 탄력적으로 운영, 사전 과대 구성 불필요
- **비용 절감**: Pay Per Use 방식으로 사용한 만큼만 비용 지불 → 온프레미스 대비 훨씬 경제적

### 1.1.3 클라우드 서비스 유형

| 유형 | 의미 | 공급자 관리 범위 |
| --- | --- | --- |
| **IaaS** (Infrastructure as a Service) | 서버·네트워크·스토리지 등 하드웨어와 가상화 제공 | 인프라(하드웨어+가상화)까지 |
| **PaaS** (Platform as a Service) | 플랫폼 영역까지 제공, 사용자는 앱 개발·관리만 | 운영체제, 미들웨어, 런타임까지 |
| **SaaS** (Software as a Service) | 애플리케이션 영역까지 전부 제공, 사용자는 서비스만 받음 | 애플리케이션까지 전체 |

### 1.1.4 클라우드 구축 모델

| 모델 | 자원 소유권 | 위치 | 서비스 주체 | 특징 |
| --- | --- | --- | --- | --- |
| **퍼블릭 클라우드** | 사용자 소유 아님 | 공급자 공간 | 클라우드 공급자 | 온디맨드, 확장성 우수, 글로벌 데이터센터로 해외 서비스 유리 (예: AWS, GCP, Azure) |
| **프라이빗 클라우드** | 사용자 소유 | 온프레미스 | 사용자 | 보안 우수, 확장성은 떨어짐 |
| **하이브리드 클라우드** | 혼합 | 양쪽 모두 | 혼합 | 퍼블릭+프라이빗 단점 보완, 시스템 간 연결 |

## 1.2 AWS 서비스

### 1.2.1 AWS 소개

- Amazon 자회사, 퍼블릭 클라우드 컴퓨팅 서비스 제공
- 200개 이상의 클라우드 서비스, 글로벌 점유율 1위
- **리전(region)**: 데이터센터가 모여 있는 물리적 지역 → 37개 (2025년 12월 기준)
- **가용 영역(AZ)**: 리전 내 개별 데이터센터 → 117개
- 한국: 서울 리전 + 가용 영역 4개

### 1.2.2 AWS 서비스 라인업 (총 23개 범주, 200개 이상 세부 서비스)

이 책에서 주로 다루는 5가지 핵심 영역:

- **컴퓨팅**: 가상 머신 생성·관리 → 대표 서비스 **EC2** (2장, 9장에서 상세)
- **네트워킹 및 콘텐츠 전송**: 자원 간 통신 지원 → **VPC, CloudFront, Route 53** (3, 4, 7장)
- **스토리지**: 안정적·확장성 높은 저장 서비스 → **S3, EFS, EBS** (5장)
- **데이터베이스**: 목적별 완전관리형 DB → **RDS, Aurora, DynamoDB** (6장)
- **보안 자격 증명 및 규격 준수**: 접근 관리 → **IAM** (8장)

### 1.2.3 AWS 과금 체계

- Pay Per Use: 사용한 만큼만 과금 (시간·사용량 비례)
