## 2.1 AWS 컴퓨팅 서비스

### 2.1.1 컴퓨팅 정의

- **컴퓨트(compute)**: 계산하다·답을 구하다·추정하다
- **컴퓨팅(computing)**: 어떤 것에 대해 계산하여 답을 구하고 추정하는 행위, 이를 전문적으로 수행하는 특화 장비가 **서버(server)**
- 서버는 온프레미스로 직접 구축할 수도 있지만, 퍼블릭 클라우드에서 자원을 제공받아 손쉽게 워크로드 수행 가능

### 2.1.2 AWS 컴퓨팅 서비스 (3가지)

| 서비스 | 특징 |
| --- | --- |
| **EC2** (Elastic Compute Cloud) | 클라우드 환경에서 서버 자원을 인스턴스(가상 머신, VM) 형태로 제공하는 가장 기본적인 컴퓨팅 서비스 |
| **Lambda** | 서버리스(serverless) 컴퓨팅 — 별도 서버 설정 없이 코드만 실행 |
| **Lightsail** | 독립적인 환경 제공, 최소 설정만으로 손쉽게 사용 가능한 플랫폼 |

→ 이 책에서는 **Amazon EC2**를 중점적으로 다룸

---

## 2.2 Amazon EC2 소개

- 퍼블릭 클라우드에서 확장 가능한 컴퓨팅 자원으로 가상 서버를 운영하는 서비스
- **Elastic(탄력적)**: 필요한 만큼 확장·축소 가능
- **인스턴스**: 클라우드 환경에서 필요한 만큼 컴퓨팅 자원을 사용하고, 끝나면 반납하는 형태의 임의 구성 가상 서버

### 2.2.1 Amazon EC2 인스턴스

**인스턴스 유형**

- 운영체제: 리눅스, 윈도우, macOS / CPU 옵션: Arm, x86
- 500개 이상의 인스턴스 유형 제공, 용도별 최적화 선택 가능
- 명명 예: `t3.micro` = 인스턴스 패밀리(t) + 세대(3) + 크기(micro)

| 분류 | 용도 | 예시 |
| --- | --- | --- |
| 범용 | 균형 잡힌 컴퓨팅 자원 | Mac, T2~T4, M5~M8 |
| 컴퓨팅 최적화 | 고성능 프로세서, 연산 집약적 앱 | C7~C8 계열 |
| 메모리 최적화 | 대규모 데이터 처리 | R5~R8, X1, X2 등 |
| 가속 컴퓨팅 | GPU 기반 고성능 컴퓨팅 | P3~P6, G3~G6 등 |
| 스토리지 최적화 | 로컬 디스크 대용량 액세스 | I3, I4, I7, I8, H1, D2, D3 |
| HPC 최적화 | 대규모 고성능 워크로드 | HPC6, HPC7 |

**인스턴스 상태 (7가지)**

- 최종 상태: 실행 중(running), 중지됨(stopped), 종료됨(terminated)
- 진행 상태: 대기 중(pending), 중지 중(stopping), 재부팅(rebooting), 종료 중(shutting-down)

| 동작 | 흐름 |
| --- | --- |
| 최초 시작 | 대기 중 → 실행 중 |
| 중지 | 실행 중 → 중지 중 → 중지됨 (재시작 가능) |
| 중지된 것 시작 | 중지됨 → 대기 중 → 실행 중 |
| 중지된 것 종료 | 중지됨 → 종료 중 → 종료됨 (영구 삭제) |
| 실행 중인 것 종료 | 실행 중 → 종료 중 → 종료됨 (영구 삭제) |

⚠️ **주의**: '중지됨'(일시 정지, 재개 가능)과 '종료됨'(영구 삭제, 복구 불가)을 혼동하지 말 것. 종료됨 상태가 콘솔에서 바로 사라지지 않아도 정상(시간 지나면 사라짐)

### 2.2.2 AMI (Amazon Machine Image)

- 인스턴스 시작에 필요한 정보(운영체제+소프트웨어 구성)를 담은 **템플릿**
- 하나의 AMI로 동일 구성의 여러 인스턴스 생성 가능
- 종류: AWS 기본 AMI / 사용자 정의 AMI / AWS Marketplace 서드파티 AMI
- 사용자 정의 AMI는 다른 리전으로 복사 가능, 불필요 시 등록 취소 가능
- 이 책 실습: AWS 기본 AMI 사용

### 2.2.3 Amazon EC2 스토리지

| 구분 | 인스턴스 스토어 | Amazon EBS |
| --- | --- | --- |
| 연결 방식 | 인스턴스에 직접 연결 | 네트워킹 연결 |
| I/O 속도 | 빠름 | 보통 |
| 데이터 보관 | 임시 (중지·종료 시 손실) | 영구 |
| 스냅샷(백업) | 불가 | 가능 |
- **인스턴스 스토어**: 인스턴스 생성 시 기본 존재하는 저장소. ⚠️ **t3.micro는 인스턴스 스토어 미지원**
- **Amazon EBS**(Elastic Block Store): 외장 하드디스크와 비슷한 개념, 연결·제거 가능한 블록 스토리지, 스냅샷 백업 가능
- 참고: 파일 스토리지 **EFS**, 오브젝트 스토리지 **S3**도 있음 (5장에서 상세)

### 2.2.4 Amazon EC2 네트워킹

- **Amazon VPC**(Virtual Private Cloud): AWS 퍼블릭 클라우드 안에서 논리적으로 격리된 가상 네트워크. EC2는 VPC 안에서 생성·통신
- **네트워크 인터페이스(ENI, Elastic Network Interface)**: VPC 내 생성되는 논리적 네트워크 인터페이스, EC2에 연결해 네트워킹 수행 (통신 케이블 장착 어댑터 비유)
- **IP 주소**
    - 프라이빗 IP: 내부 통신용 사설 IP
    - 퍼블릭 IP: 외부 통신용 공인 IP

### 2.2.5 Amazon EC2 보안

- **보안 그룹(security group)**: EC2의 송수신 트래픽을 제어하는 가상 방화벽
    - **인바운드**: 수신 트래픽 규칙 / **아웃바운드**: 송신 트래픽 규칙
    - 프로토콜, 포트 번호, IP 대역 등으로 정의
- **키 페어(key pair)**: SSH 접근 자격 증명용 보안 키
    - 퍼블릭 키 → EC2 인스턴스에 저장
    - 프라이빗 키 → 사용자 컴퓨터에 별도 보관

### 2.2.6 Amazon EC2 모니터링

모니터링 계획 수립 시 고려사항: 목표 / 대상 자원 / 빈도 / 수행 도구 / 수행할 사람 / 경보 알림 대상

| 구분 | 방식 |
| --- | --- |
| **수동 모니터링** | 관리자가 직접 콘솔·EC2 대시보드·CloudWatch로 통계 확인 |
| **자동 모니터링** | **지표에 임곗값 설정 → 조건 충족 시 CloudWatch 경보(alarm) 발생 → Amazon SNS로 알림 전송 or 오토 스케일링과 연계해 인스턴스 확장 등 후속 동작 수행** |
- 주요 지표: CPU Utilization, Disk Read/Write, Network In/Out 등

### 2.2.7 Amazon EC2 인스턴스 구입 옵션

| 옵션 | 특징 |
| --- | --- |
| **온디맨드** | 초 단위로 사용한 만큼 비용 지불 |
| **Savings Plans** | 1년/3년 약정, 일관된 컴퓨팅 사용량에 할인 |
| **예약 인스턴스** | 1년/3년 동안 인스턴스 유형·리전 약정 |
| **스팟 인스턴스** | 미사용 중인 인스턴스를 경매 방식으로 할당(저렴) |
